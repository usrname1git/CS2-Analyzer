Measurement, not a verdict. Damage-to-kill timing is not reaction time or first visibility. Rank is not verified. The analyzer does not infer cheating probabilities; zero denominators remain N/A.

INGRESS

One private job directory

Stream accepted bytes to quarantined SSD storage, hash as they arrive, and enforce limits before decoding. Never publish a general directory share.

upload → seal → validate

EXECUTION

One bounded CPU worker

Pinned CSDA decoder, native C++ analyzer, no GPU slot. Restricted execution and a durable queue keep heavy or broken demos from overwhelming the host.

CSDA → JSON → C++ report

DELIVERY

Results, then cleanup

Publish only verified artifacts for the authenticated job owner. Show real stages, never a fabricated ETA. Expiry and failed deletion remain observable.

verify → render → expire
